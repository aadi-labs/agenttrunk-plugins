The documentation site's MCP server answers questions about these public guides.
It does not sign in to AgentTrunk, upload context, or read private workspaces.
Use the CLI or SDK below for authenticated product operations.

Native registration helpers are available for TypeScript, Python, Go, Rust,
Ruby, and Swift. Follow the [language-specific authentication guide](https://github.com/aadi-labs/agenttrunk-plugins/blob/main/docs/native-agent-auth.md)
for discovery, human approval, token exchange, and explicit refresh.
Use [skill sync](/guides/skill-sync) to pull verified context and push local edits.
`agenttrunk auth logout --yes` clears local credentials, not server-side grants.

Give a terminal-capable agent this task:

```text
Set up AgentTrunk for this project.
Read https://docs.agenttrunk.ai/quickstart.md and
https://docs.agenttrunk.ai/authentication.md first.
Reuse existing authorized credentials if available. Otherwise initiate
human-approved registration and give me the verification link.
Do not read my inbox, cookies, or passwords. Ask me for the approval code.
List workspaces and ask which one to use if my intent is ambiguous.
Do not upload context or change production as part of this setup task.
Report installation, authentication, and workspace access separately.
```

## If your human is new

They [sign up](https://www.agenttrunk.ai/signup) and complete organization
onboarding. Existing users [sign in](https://www.agenttrunk.ai/login).
Then the agent completes the approval flow described in [authentication](/authentication).

## Discover only what you need

Use [/docs/llms.txt](/llms.txt) to choose a page, then append `.md` to read
that guide as Markdown. Use the API reference for exact fields rather than
guessing routes. The [public source](https://github.com/aadi-labs/agenttrunk-plugins/tree/main/fern/pages)
can be inspected without signing in.

## Skills and MCP

The portable skill teaches the workflow; it is not a credential. Install it
using the [integration guide](/integrations).

Connect to [operational MCP](/guides/mcp) for private workspace operations using
securely supplied bearer credentials. Documentation search is separate and cannot
upload or release context. Verify the deployed connection before claiming success.
